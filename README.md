## DiaCalc

React version of DiaCalc, originally written in C++, then in Java, and later in pure JavaScript.

### Status

The project is still in **alpha** and is **not** planned for public release yet.

### Migration

I plan to make migration smooth for existing users. All data will be converted to the new version, along with login credentials.

If you can log in at [https://online.diacalc.ru/](https://online.diacalc.ru/), you should be able to log in at [https://react.diacalc.ru/](https://react.diacalc.ru/) as well.

If you cannot log in, contact me at connie@diacalc.ru.

### Recommendation

For now, use [https://online.diacalc.ru/](https://online.diacalc.ru/). The React version still has many features to implement.
